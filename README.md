# Olist E-commerce Analysis

Проект по анализу данных бразильского маркетплейса Olist.

Цель проекта — пройти полный путь работы с данными: от загрузки и очистки исходных CSV-файлов до хранения данных в PostgreSQL, исследовательского анализа и проверки статистических гипотез.

## Задачи проекта

В рамках проекта реализованы:

* загрузка исходных данных;
* очистка и преобразование данных;
* валидация типов и значений;
* загрузка обработанных данных в PostgreSQL;
* проектирование структуры базы данных;
* написание аналитических SQL-запросов;
* исследовательский анализ данных;
* визуализация;
* проверка статистических гипотез;
* формирование выводов по данным.

## ETL-пайплайн

Проект разделён на три основных этапа.

### Extract

Скрипт извлекает исходный набор данных Olist и сохраняет CSV-файлы в директорию:

```text
data/raw/
```

### Transform

На этапе преобразования выполняются:

* обработка пропущенных значений;
* удаление и анализ дубликатов;
* приведение типов данных;
* обработка временных признаков;
* проверка денежных значений;
* проверка географических координат;
* сохранение ZIP-кодов как строк для предотвращения потери ведущих нулей;
* подготовка данных для загрузки в PostgreSQL.

Обработанные данные сохраняются в:

```text
data/processed/
```

### Load

Данные загружаются в PostgreSQL.

В базе данных используются:

* primary keys;
* foreign keys;
* составные ключи;
* CHECK constraints;
* связи между таблицами;
* UPSERT через `ON CONFLICT` для повторяемой загрузки данных.

## Статистический анализ

В проекте формулируются и проверяются бизнес-гипотезы.

В зависимости от типа данных используются:

* t-test;
* Mann–Whitney U test;
* Chi-square test;
* Kruskal–Wallis test.

Пример гипотезы:

> Зависит ли время доставки заказа от штата покупателя?

### H0

Распределение времени доставки не различается между штатами.

### H1

Между штатами существуют статистически значимые различия во времени доставки.
